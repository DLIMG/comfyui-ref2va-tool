# Ref2VA 项目结果持久化设计

## 目标

解决两个问题：再次导入同一个制作 JSON 时不丢失已经生成的视频关联；新收集的视频保存在短剧项目目录中，而不是只放在工具自身的 `data` 目录。

## 项目目录

故事板 JSON 顶层新增可选字段：

```json
"project_dir": "G:\\AI短剧生成\\送错的密令_项目"
```

当前《送错的密令》JSON 和网页故事板写入该字段。未配置 `project_dir` 的旧项目继续使用工具原有的 `data/results`，保持兼容。

## 视频保存

配置项目目录后，新收集结果保存到：

```text
<project_dir>\06_生成视频\<片段号>\<结果ID>\视频文件.mp4
```

网页结果记录中的 `path` 指向这个项目内副本。ComfyUI 原始输出继续保留，不移动、不删除。已有的 01A、01B 结果复制迁移到项目目录并更新网页记录。

结果删除仍只允许删除受管理的结果文件；允许范围为当前项目的 `06_生成视频` 与旧版 `data/results`，不能删除范围外文件。

## 再次导入 JSON

导入时按片段 `id` 与当前故事板匹配：

- 新 JSON 更新标题、参考图、提示词、时长、种子、清晰度、画幅和输出名。
- 同 ID 片段保留当前的 `results`、`prompt_id`、`run_dir`、`status` 和运行错误。
- 新 JSON 明确携带非空 `results` 时，以导入内容为准，便于迁移完整导出文件。
- 新片段正常加入；当前故事板中已不存在于导入 JSON 的片段不保留。
- `project_dir` 优先采用导入 JSON 中的值；没有时保留当前项目值。

## 错误处理

- `project_dir` 不是绝对路径或不能创建 `06_生成视频` 时，结果收集返回清楚错误，不影响 ComfyUI 原始输出。
- 导入 JSON 格式错误时不覆盖当前故事板。
- 已记录视频文件缺失时保留结果记录并由播放器显示加载失败，不静默删除。

## 测试

- 导入同 ID 的原始 JSON 后保留已有结果和运行字段。
- 导入带非空结果的完整 JSON 时采用导入结果。
- 新旧片段增删和 `project_dir` 合并规则正确。
- 配置项目目录后结果复制到 `06_生成视频`。
- 未配置项目目录时保持旧结果目录行为。
- 删除操作只允许两个受管理结果根目录。
- 完整测试集以及连续预览播放列表测试继续通过。

## 不在本次范围

- 不移动或删除 ComfyUI 原始输出。
- 不自动拼接最终成片。
- 不增加多项目数据库或项目选择器。
