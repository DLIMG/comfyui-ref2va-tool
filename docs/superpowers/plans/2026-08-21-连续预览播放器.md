# Ref2VA 连续预览播放器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在故事板顶部增加按分镜顺序连续播放每段最新结果的网页播放器。

**Architecture:** 新增独立的 `playlist.js` 纯函数模块负责从故事板构建稳定播放列表并计算刷新后的索引；`app.js` 只负责把列表绑定到原生 `<video>`、处理切段和更新界面。后端与视频文件接口保持不变，继续使用 `/api/results/video/{shot_id}/{result_id}`。

**Tech Stack:** 原生 HTML/CSS/JavaScript、HTML5 Video、pytest、Node.js（仅用于纯 JavaScript 单元测试）
